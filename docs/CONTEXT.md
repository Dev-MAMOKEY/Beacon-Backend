# 마모키 비콘 출석 시스템 — 공유 도메인 언어

백엔드(`beacon_backend`) · 프론트(`beacon_frontend`) · 별도 Flutter 앱 · ESP32 비콘으로 구성된 동아리 출석 시스템의 공유 용어집. 기본 용어 정의는 기능명세서 §1을 따르고, 이 문서는 **혼동이 잦거나 결정으로 확정된 용어만** 날카롭게 고정한다.

## 두 종류의 "코드" — 반드시 구분

**초대코드 (Invite Code)**:
동아리 **가입**용. 관리자가 발급하는 **4자리 랜덤 영숫자**(A–Z, 0–9). 동아리당 유효 코드 1개이며 재발급 시 이전 코드는 자동 무효화. 발급/조회/무효화 `…/clubs/{clubId}/invite-code`, 가입 `POST /clubs/join`.
_Avoid_: 가입코드, 출석코드, OTP

**출석 OTP (Attendance Code / 출석 비밀번호)**:
**출석 체크**용. 세션 시작(ACTIVE) 시 **세션별로** 생성되는 **4자리** 코드. 해시로 저장하고 관리자 화면에만 평문 노출, 세션 종료 시 만료. 앱에서 비콘 감지 후 입력.
_Avoid_: 초대코드, 계정 비밀번호

> 둘 다 "4자리 코드"라 섞이기 쉽다. **초대코드 = 가입, 출석 OTP = 출석**으로 항상 구분한다.

## 기타 확정 용어

**동아리 생성 (Club Creation)**:
`POST /clubs/create`. 요청한 멤버가 **자동으로 ADMIN**이 된다. (기능명세서 원본 §15에는 없었으나 실제 구현·배포된 진입점 — v2.1에서 명세서에 역반영)
_Avoid_: 동아리 등록
